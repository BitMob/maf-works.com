在桌面端網站首頁右側填充作品記錄照片 Slider，照片來源於網站每個作品圖片隨機選取，並套用 CMYK Halftone 效果：colorK 定義為網站主題色之一 —— Crimson (DC143C)。此 Slider 模塊的 Break Point 為 1000px，因此手機上依然不會顯示，iPad 可以。
	
原網站的 main body 恆定為 378px，網頁在桌面端瀏覽器中右側會顯示為大面積空白。因為最近手癢，就實驗看看。

Art Director: maf-works.com

On the desktop version of the website, a slider featuring documentation images of the works has been added to the right-hand side of the homepage. The images are randomly selected from each work's image gallery and rendered with a CMYK halftone effect, with `colorK` set to Crimson (`#DC143C`), one of the website's theme colors. The breakpoint for this slider module is 1000px, so it remains hidden on mobile phones but is visible on iPads.

The original website has a fixed main body width of 378px, leaving a large blank area on the right when viewed in a desktop browser. I recently felt like experimenting, so I decided to try this out.
